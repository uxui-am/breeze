# Breeze — holiday apartments in Los Gigantes, Tenerife

**Live:** https://breeze-redesign.vercel.app

UX/UI redesign concept for a website of three holiday apartments — Ocean, Atlantic and Summer Breeze.
Design & development: Alina M. — [@uxui_am](https://instagram.com/uxui_am)

- Booking flow: pick dates and guests → instant price → book via WhatsApp
- Languages: RU / EN / ES (`?lang=en`, `?lang=es`)
- Apartment pages: `?apartment=ocean | atlantic | summer`
- Mobile-first, design system in Figma
- Media on Cloudinary, hosting on Vercel
- PageSpeed (mobile): 99 / 100 / 100 / 100
